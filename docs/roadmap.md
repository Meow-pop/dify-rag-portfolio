# Roadmap

## Milestone 1: reproducible deployment

- Run Dify through Docker Compose
- Record host requirements and container health checks
- Pin the Dify release and document upgrades
- Verify restart and data persistence

## Milestone 2: useful RAG application

- Add public sample documents
- Define chunking and metadata rules
- Build a workflow that returns citations
- Expose the application through an API

## Milestone 3: evaluation

- Create a question-and-answer test set
- Measure retrieval hit rate and citation correctness
- Compare chunk sizes and top-k values
- Record latency and memory consumption

## Milestone 4: engineering depth

- Add automated document ingestion
- Switch between a cloud model and Ollama
- Add structured logs and basic monitoring
- Add a CI check for scripts and evaluation code
- Publish an architecture diagram and demonstration video
