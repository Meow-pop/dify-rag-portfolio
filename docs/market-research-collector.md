# 淘宝市场调研采集器

## 目标

这个浏览器扩展由用户主动触发，读取淘宝或天猫当前页面已经加载并渲染的公开商品卡片，导出 JSON 或 CSV，作为市场调研的原始证据。它不是无人值守爬虫，不自动翻页，不读取 Cookie，也不绕过验证码或访问限制。

扩展目录：`market-research/browser-collector/`

## 安装

Chrome：

1. 打开 `chrome://extensions`。
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择仓库中的 `market-research/browser-collector` 目录。

Edge：

1. 打开 `edge://extensions`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择同一个目录。

安装扩展会新增浏览器权限，应由用户本人在浏览器中确认。

## 使用

1. 正常登录淘宝或天猫并搜索产品。
2. 滚动页面，让需要研究的商品卡片完成加载。
3. 点击“星桥市场调研采集器”。
4. 点击“采集当前页”。
5. 检查商品数量，再下载 JSON 或 CSV。

输出字段：排名、标题、价格文本、数值价格、店铺、销量线索、地区、商品链接、图片链接。文件同时记录来源页面、搜索词、采集时间和采集模式。

## 安全和合规边界

- 只处理当前页面已经展示的公开商品信息。
- 不自动登录，不读取或导出 Cookie、Local Storage、密码和个人资料。
- 不自动翻页，不实现并发抓取、代理池、指纹伪装和验证码破解。
- 出现访问频繁、滑动验证、安全验证或验证码时停止。
- 默认最多处理 100 个唯一商品链接。
- 导出的 CSV 会防止以 `= + - @` 开头的单元格被电子表格当作公式执行。
- 使用前应确认目标页面条款和适用法律允许当前用途。

## 已知限制

淘宝页面使用动态渲染和经常变化的类名。采集器优先依赖商品链接和语义特征，而不是单一 CSS 类名，但平台改版后仍可能出现字段缺失。此时保留一份不含个人信息的页面截图和导出文件，用于更新解析规则。

版本 `0.1.1` 起支持淘宝搜索结果中常见的 `click.simba.taobao.com` 广告跳转链接，并会优先从链接参数或商品卡片属性中恢复商品 ID。

版本 `0.1.2` 增加价格节点回溯：即使商品卡片没有可直接识别的链接，也会从 `¥/￥` 价格元素反向定位商品卡片。零结果提示会同时显示已发现的链接、价格和候选卡片数量，方便定位淘宝页面改版。

版本 `0.1.3` 增加开放 Shadow DOM 递归查询和页面框架聚合，并兼容货币符号由 CSS 绘制、DOM 文本中只有价格数字的结构。

版本 `0.1.4` 为兼容 Edge，改为由当前标签页内已注入的内容脚本广播并回传各框架结果，同时移除 `webNavigation` 权限。

当前版本不会把结果自动上传到 Dify。下一阶段将先验证导出质量，再增加数据清洗、去重和市场调研工作流。

## 小红书路线

小红书将作为独立适配器，仅支持用户主动打开并加载的公开搜索或笔记页面。它遵守同样的停止条件和隐私边界，不做无人值守批量采集。
